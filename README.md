# Tic-Tac-Toe

A simple command-line Tic-Tac-Toe game written in C++.

## What I Made

- Two-player game: X vs O
- Players choose squares 1–9
- Detects wins and draws
- Prevents invalid or occupied moves
- Displays the board in the terminal

## What I Used

- C++
- `iostream`
- `array`

## Notes

Built this as a small C++ project to practice arrays, functions, loops, conditionals, and basic input handling.
